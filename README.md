# Folder gambar menu

Taruh file logo resmi Badan Gizi Nasional di sini dengan nama `logo-bgn.png` (download dari sumber resmi BGN, jangan pakai logo hasil generate AI). Kalau file belum ada, header akan menampilkan kotak placeholder bertulisan "BGN".

Taruh foto menu harian di sini, beri nama sesuai hari, misalnya:

- senin.jpg
- selasa.jpg
- rabu.jpg
- kamis.jpg
- jumat.jpg
- sabtu.jpg

Nama file harus sama persis dengan yang ditulis di kolom `"gambar"` pada `data/menu.json`.
